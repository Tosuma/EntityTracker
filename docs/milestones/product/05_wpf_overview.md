# Milestone 5 — First Usable WPF Overview

## Goal
Produce the first end-to-end desktop application.

## Tasks
- Use MVVM.
- Show dependency-safe rank, table/entity name, status, dependency count, and basic progress information.
- Add an `Import CSV` file-picker action.
- Parse and preview a selected CSV; full synchronization comes next.
- Display validation and cycle errors clearly.
- Keep ViewModels focused on presentation/orchestration.

## Acceptance criteria
- Manager can double-click the app and see persisted data.
- No terminal or local web server is required.
- UI contains no graph algorithm, SQL, CSV parsing, or persistence logic.
- Realistic schemas remain responsive.
